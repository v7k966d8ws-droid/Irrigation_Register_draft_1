DD PRODUCE — IRRIGATION REGISTER — BUILD 1

Open index.html in a browser to test the spreadsheet-like editing experience.
For GitHub Pages: upload index.html to the root of a repository and enable Pages from the main branch root.

Tap cells to edit; select a farm then choose multiple outlets. Add row or duplicate the last row.
Changes are saved to browser localStorage on the current device/browser only. No cloud sync.
Use Export CSV for Excel and Backup JSON regularly. Import backup restores a JSON backup.

TEST LIMITATIONS:
- Farm/outlet names are initial working lists, not verified against the complete 62-block master list.
- Fertilizer is one dropdown category per row; detailed multi-product fertigation is not included yet.
- Local storage can be cleared by browser settings/private browsing and does not sync across devices.
- This is a usability prototype, not AquaLink programming software.
